# RELAY

Ночное радио колонны. Godot 4: одна схема «карьерный перегон», четыре главы — территории открываются по сюжету.

Открой папку в Godot 4.3+ (рендер Compatibility) и запусти F5: интро → главное меню.

- главы и обучение — `docs/DEMO.md`
- визуал — `docs/VISUAL.md`
- концепт — `docs/RELAY-koncept.docx`

Прогресс: `user://relay_progress.cfg`. **Новая игра** сбрасывает прогресс и стартует обучение. **Продолжить** — с текущей главы.

Цвета только из `scripts/palette.gd`. Штампы: `python tools/make_icons.py`.
