# Визуал Relay

Не фильм. Диспетчерская панель: штамп, силуэт, восемь красок.

Источник правды по ощущению — `docs/RELAY-koncept.docx`.

## Якорь

Зелёная волна рации. Только она «жива». Всё остальное — грязный металл и пыль.
На остановке волна почти плоская (ветер и металл). Под мачтой — слова целые, тег «ЧИСТО».

## Палитра

Источник правды: `scripts/palette.gd`. В сценах не придумывать новые цвета.

| Имя | Зачем |
|---|---|
| INK / INK_RAISED | ночь, панели |
| DUST / DUST_DIM | тепло, пыль, земля |
| CRT / CRT_DIM | живой эфир |
| AMBER | вызов, выбор |
| RUST | отказ, насечка, сорванная пломба |
| STEEL | рамки |
| JAM | глушение, клетка В, ложный пин |
| PAPER / PAPER_DIM | текст |

## Законы

- Нет лиц, нет 3D, нет уникальных траков.
- Фура = прямоугольник + подпись.
- Человек = кружок с буквой.
- Узел = точка. Живая вышка — зелёная точка сверху.
- Тепло рисуется, только если антенна жива.
- Ложная точка — серо-синяя, когда частота не та или мгла густая.
- Движение: пыль ползёт, волна дрожит, пин дышит. Больше не надо.

## Ассеты

Не рисуем пустыню. Делаем **штампы 64px** в палитре.

- исходник генератора: `tools/make_icons.py`
- картинки: `assets/icons/`
- в игре грузит `scripts/icons.gd`

Пересобрать штампы: `python tools/make_icons.py`

## Рефы

Ночной CB, накладная, Mini Metro, осциллограф. Не Mad Max, не красивая стратегия с земли.
