# Демо-срез Relay

## Одна локация, четыре главы

Одна схема — **карьерный перегон**. Территории открываются после глав по сюжету.

| id | Глава | Что открывается на схеме |
|---|---|---|
| **0** | Обучение | Посёлок **Кольца** (дворы) |
| **1** | Кольца | **Соль** (плешь) |
| **2** | Соль | **Вышка 14** |
| **3** | Вышка 14 | Финиш демо (эфир под мачтой) |

Старт: интро → меню. **Новая игра** сбрасывает прогресс (и мета-флаги). **Продолжить** — текущая глава.

Прогресс: `user://relay_progress.cfg`. **Esc** — в меню.

## Вышка: ремонт → настройка

У **Вышки 14** сейчас `needs_repair = true`.

1. Нужен **механик** (токен «Мх»). Пока без станции: **M** выдаёт механика (dev). В главе 0 у мачты и в главе 3 он выдаётся сам.
2. Кликни **Мх** на ленте (или **M**, если уже есть) → кликни вышку на схеме → ремонт идёт сам (0→100%).
3. Пока механик чинит — его нет для других задач.
4. У вышки: **N** или клик по точке → **настройка** (заглушка, всегда успех) → связной / эпilogue.

Позже: станция механика, валюта, мини-игры настройки.

## Глава 0 — обучение

Шаги как раньше (лента → ВЕЩЬ → пломба → Кольца → Б → медик → …). У вышки 14: механик → ремонт → настройка → лист.

## Главы 1–3

1. Накладная → дорога на схеме.
2. Вызов: **1 = А**, **2 = Б**.
3. Глава 3: доезд до 14 → ремонт (если не сделан заранее) → настройка → эфир.

**P** — пломба. **M** — механик / режим отправки. **N** — настройка вышки.

## Имена

- **Кольца** — посёлок, дворы.
- **Соль** — плешь.
- **Вышка 14** — ремонт + настройка + мачта.

## Карта / UI в редакторе

Визуал — ноды в `Main.tscn` (маркеры, рёбра, карточки, лента, рация, шапка).  
Код только биндит `Game` → ноды. Новая точка = Add Child под `RouteMap/Markers`.
