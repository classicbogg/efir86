# Демо-срез Relay

## Уровни

| id | Что |
|---|---|
| **0** | Обучение — ведомый прогон основных механик |
| **1** | Карьер → Соль/Кольца → Вышка 14 → итог |

Старт: экран выборки (`LevelSelect`). Меню позже подменит скин, логика та же.

Прогресс: `user://relay_progress.cfg`. В выборке клавиша **R** — сброс (dev). **Esc** из ночи — назад к списку.

## Уровень 0 — обучение

Шаги: смена → накладная (ВЕЩЬ) → пломба/сдвиг → Кольца → рычаг Б → переспрос → слать → медик → мачта → лист.

Space — «дальше» на шагах с подсказкой. Таймер вызова не сжигает смену.

## Уровень 1 — как пройти

1. Возьми одну накладную: **ФУРА** / **ДОГОВОР** / **ВЕЩЬ**.
2. На карте **Соль** (плешь) или **Кольца** (дворы).
3. Вызов: рычаг **1 = А**, **2 = Б**. Не та частота — ложный пин.
4. Переспрос или «шлю» → клик по кружку на ленте.
5. Вышка 14 → связной → чистые голоса → накладная итога.

**P** — пломба на остановке.

## Что нарочно не в демо

Три развилки полной ночи, частота В, охрана, выезд в пыль, мета, звук-голоса.
